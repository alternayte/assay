Purpose

The Payments API takes card payments for Acme Journals. Team Hermes owns it.

The API is part of the Billing system.

Endpoints

EndpointMethodUse
/paymentsPOSTTake a payment
/payments/{id}/refundPOSTRefund a settled payment

Dependencies

  • The Payments API depends on the Ledger service.
  • It calls the Fraud check API for each payment.
    • The call times out after 2 seconds.
