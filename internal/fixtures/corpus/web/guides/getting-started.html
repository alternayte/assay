Getting started

A client sends a payment to the Payments API with an idempotency key. The payments team owns the API.

Send the first payment

  1. Create a client in the portal.
  2. Send POST /payments with the amount and the currency.
  3. Read the payment status from the response.

When a request fails, follow the retry guide. See the partner status page for outages.

Open the console to try a request.
